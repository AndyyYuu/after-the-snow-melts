# 《等雪融化以后》可玩剧情原型

这是一款原创的俯视角像素叙事游戏原型。玩家操纵走进记忆的弥洛，在冻结的过去场景中调查物件、收集七枚记忆碎片，并逐渐理解莱恩没有被她察觉的感情。

## 启动

- 双击 `启动游戏.bat`；或
- 直接使用浏览器打开 `index.html`。

游戏为纯本地静态网页，不需要安装依赖或联网。

## 操作

- `WASD` 或方向键：沿 32px 单元格移动
- `E`、`Enter` 或空格：调查、进入对话、继续对话
- `J`：打开或关闭记忆日志
- 移动端：使用画面上的方向键和 `E` 按钮

## 已实现内容

- 八个连续剧情场景与完整结局
- 七枚记忆碎片及收集日志
- 基于单元格的移动、调查点和触发距离
- 场景转场、对话打字效果、雨雪粒子与碎片提示
- 人物、背景和游戏环境概念图整合
- 桌面和触屏自适应操作

## 原型说明

当前版本使用完整场景概念图作为背景，并在其上叠加 32px 逻辑瓦片、角色和交互层。进入记忆后，背景中已经存在的人物代表被冻结的过去；玩家操纵的带微光小精灵代表现在的弥洛。

后续若进入正式制作阶段，可使用 Concept Art 包中的环境瓦片与角色四方向参考，将背景拆分为真正的 TileMap、碰撞层和动画精灵表。
