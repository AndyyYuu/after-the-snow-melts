# 《等雪融化以后》可玩剧情原型

这是一款原创的俯视角像素叙事游戏原型。玩家操纵走进记忆的弥洛，在冻结的过去场景中调查物件、收集七枚记忆碎片，并逐渐理解莱恩没有被她察觉的感情。

## 启动

- 双击 `启动游戏.bat`；或
- 直接使用浏览器打开 `index.html`。

游戏为纯本地静态网页，不需要安装依赖或联网。

## 操作

- `WASD` 或方向键：沿 32px 单元格移动
- `E`、`Enter` 或空格：调查、进入对话、继续对话
- `J`：打开或关闭记忆日志
- 移动端：使用画面上的方向键和 `E` 按钮

## 已实现内容

- 八个连续剧情场景与完整结局
- 七枚记忆碎片及收集日志
- 基于 32px 单元格的移动、调查点和真实场景碰撞
- 场景转场、对话打字效果、雨雪粒子与碎片提示
- 七张无人物纯环境地图与四组独立方向精灵
- 墙壁、悬崖、水域、栏杆、家具与 NPC 均不可穿越
- 桌面和触屏自适应操作

## 原型说明

当前版本已经将环境与人物彻底拆开：背景图只保留建筑、道路与物件，弥洛、年轻莱恩、老年莱恩和诺娅全部由透明精灵表实时绘制。人物会按朝向切换待机/行走帧，并依照脚下位置排序遮挡关系。

每个场景都有独立的可通行区域和实体障碍层。角色只能沿地图中的地面、道路、楼梯和桥梁移动，不能穿过墙壁、悬崖、水域、栏杆、家具或其他人物。
